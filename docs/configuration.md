# Настройка

Есть два уровня настроек: команда CLI для всего сервера и выбор нейросети для отдельной кампании. Настройки кампании открываются через «Управление кампанией» → «Нейросеть».

## CLI по умолчанию

Сервер запускает команду `claude` с аргументом `-p`. CLI-клиент нужно установить и авторизовать отдельно. Он должен быть доступен в `PATH` того терминала, из которого запускается `pnpm dev`.

Чтобы изменить команду, создайте `.env` в корне проекта на основе [.env.example](../.env.example):

```dotenv
MASTER_AI_LLM=cli
MASTER_AI_LLM_CMD=claude
MASTER_AI_LLM_ARGS=-p
```

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `MASTER_AI_LLM` | `cli` | Тип серверного провайдера. Поддерживается только `cli`. |
| `MASTER_AI_LLM_CMD` | `claude` | Исполняемая команда CLI. |
| `MASTER_AI_LLM_ARGS` | `-p` | Аргументы команды, разделённые пробелами. |

Штатная команда разработки сервера читает корневой `.env`. После изменения файла перезапустите `pnpm dev`. Можно передать эти же переменные через окружение процесса.

Сервер передаёт запрос в стандартный ввод CLI и читает текст ответа из стандартного вывода. Процесс запускается из временного каталога. При замене команды используйте клиент с таким же способом работы. Строка аргументов делится по пробелам: сложное shell-экранирование и аргументы с пробелами не поддерживаются.

## OpenAI-совместимый API для кампании

1. Откройте кампанию и перейдите в «Управление кампанией».
2. В разделе «Нейросеть» выберите «OpenAI API».
3. Заполните API-ключ, название модели и при необходимости Base URL. Дождитесь сохранения полей.

Пустые поля модели и Base URL используют значения из кода: `gpt-4o-mini` и `https://api.openai.com/v1`. Для совместимого сервиса укажите его модель и базовый адрес с API-префиксом, например `https://host/v1`. Сервер добавляет к нему `/chat/completions` и ожидает потоковый ответ Chat Completions.

С непустым API-ключом выбранные параметры применяются к ИИ-функциям этой кампании. Пустой API-ключ включает CLI-провайдер, даже если переключатель стоит на «OpenAI API». Совместимый сервис должен принимать используемый приложением формат запросов; поддержка любого сервиса с похожим названием API не гарантируется.

Ключ вводится в интерфейсе и хранится в локальной базе. Переменные вроде `OPENAI_API_KEY` приложение не читает; в корневом `.env` настройка API-ключа не предусмотрена.

## Адреса и данные

| Параметр | Значение при штатном запуске |
| --- | --- |
| Интерфейс Vite | `http://localhost:5173` |
| API Fastify | `http://127.0.0.1:5174` |
| База SQLite | `packages/server/data/master-ai.sqlite` |
| Автоматические копии | `packages/server/data/backups/` |

Порт API и путь рабочей базы заданы в серверном коде, порт и прокси интерфейса — в конфигурации Vite. Переменные для их изменения не предусмотрены. При занятом порте Vite может выбрать следующий свободный порт и вывести его в терминал.

При использовании ИИ контекст отправляется выбранному клиенту или API. О хранении секретов и границах локального запуска читайте в [SECURITY.md](../SECURITY.md).
