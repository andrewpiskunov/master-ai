## P0 — баги

### 1. Карточка «Применить к документу» «оживает» после перезахода
Контекст: у легаси-правок нет ключа в `fields.appliedDocBlocks` (проверено на живом документе сессии — поле отсутствует), и срабатывает ненадёжный fallback — точное сравнение текста (`isApplied()`, `packages/web/src/pages/DocumentAssistant.tsx:263-267`), которое ломается на сложном форматировании из-за лоссивого раунд-трипа `markdownToDoc → pmText`.

- [x] Добавить карточке третье состояние «устарело»: блока нет в `appliedDocBlocks` И документ менялся после сообщения → вместо активной кнопки показывать «Документ изменился, предпросмотр неактуален» (закрывает и легаси-чаты)
- [x] `DocumentPage.tsx:417-424`: писать ключ функциональным обновлением `fields` и одним PATCH вместе с контентом (как в `PlaySession.tsx:190-199`) — закрывает гонку «применил и сразу ушёл» (PATCH не await'ится, автосейв дебаунс 700 мс) и затирание ключа при двух применениях подряд (`fields` из замыкания рендера, сервер не мержит)
- [x] Тест: применить блок со сложным форматированием (списки, жирный, цитаты), перезайти в документ — карточка остаётся «Применено»

### 2. Дубликаты сущностей при создании из предложений ИИ («Песнь Хора» ×3)
