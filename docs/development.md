# Разработка

Проект использует pnpm workspaces и TypeScript с ES-модулями. Подготовка Node.js и зависимостей описана в [первом запуске](getting-started.md).

## Команды из корня

| Команда | Назначение |
| --- | --- |
| `pnpm dev` | Запустить API и интерфейс с перезапуском при изменении исходников. |
| `pnpm test` | Выполнить тесты всех пакетов. |
| `pnpm typecheck` | Проверить типы во всех пакетах. |
| `pnpm build` | Собрать интерфейс в `packages/web/dist`. |
| `pnpm docs:check` | Проверить локальные ссылки документации и демонстрационные данные. |
| `pnpm check` | Последовательно выполнить проверку типов, тесты, сборку интерфейса и проверку документации. |

Для работы только с одним пакетом используйте фильтр:

```sh
pnpm --filter @master-ai/server test
pnpm --filter @master-ai/web dev
pnpm --filter @master-ai/shared typecheck
```

Тесты лежат рядом с кодом в файлах `*.test.ts` и `*.test.tsx`. Серверные тесты используют временные базы и тестовые LLM-провайдеры. Они не требуют API-ключей и не должны обращаться к рабочей базе пользователя.

## Где искать код

| Путь | Содержимое |
| --- | --- |
| `packages/server/src/routes` | HTTP-маршруты. |
| `packages/server/src/services` | Операции с кампаниями, документами, беседами, поиском и переносом данных. |
| `packages/server/src/db` | Подключение SQLite и таблицы Drizzle. |
| `packages/server/src/llm` | Контракт провайдера, CLI, OpenAI-совместимый API и разбор ответов. |
| `packages/web/src/app` | Вход в приложение, маршрутизация и общие стили. |
| `packages/web/src/features` | Интерфейс кампаний, документов, помощника и режима игры. |
| `packages/web/src/ui` | Общие элементы интерфейса. |
| `packages/web/src/api` | HTTP-клиент и чтение потоковых ответов. |
| `packages/web/src/lib` и `packages/web/src/hooks` | Вспомогательные функции и общие React-хуки. |
| `packages/shared/src/schemas` | Схемы и типы общих данных. |
| `packages/shared/src/registries` | Типы документов, подписи и шаблоны. |
| `packages/shared/src/lib` | Общие функции без привязки к серверу или браузеру. |

Общий пакет подключается через `@master-ai/shared`. Публичный вход — `packages/shared/src/index.ts`; внутренние пути не должны становиться зависимостью других пакетов.

## База и миграции

Рабочая база при `pnpm dev` находится в `packages/server/data`. Миграции из `packages/server/drizzle` применяются сервером при открытии базы. Не меняйте уже применённые миграции: создавайте новую и проверяйте её на отдельной базе.

Перед экспериментами с данными сохраните [полную резервную копию](backup-and-updates.md). Не используйте свою игровую кампанию как тестовую фикстуру.

## Перед pull request

Запустите `pnpm check` на Node.js из `.nvmrc`. Для изменений интерфейса проверьте затронутый сценарий в браузере и приложите скриншот с демонстрационными данными. При изменении формата переноса проверьте экспорт и повторный импорт со связями между документами.

`pnpm build` собирает интерфейс, а типы серверного и общего пакетов проверяет `pnpm typecheck`. Поддерживаемый способ локального запуска описан через `pnpm dev`; отдельного сценария размещения приложения на публичном сервере документация не задаёт.

Правила оформления вклада: [CONTRIBUTING.md](../CONTRIBUTING.md).
