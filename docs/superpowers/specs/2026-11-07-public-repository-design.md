# Подготовка master-ai к публикации

Пользователь поручил восстановить удалённые исходники и выполнить предложенные улучшения публичного репозитория. Docker и Compose исключены по его просьбе.

## Результат

- Главный README на русском и английская версия: назначение, реальные скриншоты, проверенный локальный запуск, возможности, ограничения и навигация.
- Сохранены pnpm workspaces и имена `@master-ai/server`, `@master-ai/web`, `@master-ai/shared`. Внутри пакетов код сгруппирован по назначению; тесты остаются рядом с кодом.
- Документация по архитектуре, разработке, настройке ИИ, обновлению и резервному копированию. Старые планы разработки сохраняются как история и не заменяют актуальное руководство.
- MIT, руководство для участников, правила поведения и сообщения об уязвимостях, шаблоны issues и PR, roadmap и changelog.
- Автоматические проверки установки, тестов, типов, сборки и документации. Версии Node.js и pnpm указаны явно.
- Вымышленная демонстрационная кампания в существующем JSON-формате импорта. Изображения для README создаются на демонстрационных данных.

## Подход

Выбран умеренный рефакторинг существующего приложения. Одно оформление README не решает путаницу в пакетах и запуске; смена стека или глубокая переработка бизнес-логики для публикации не нужны. Русский остаётся языком интерфейса, английская версия README описывает это явно.

## Ограничения

- Не менять существующую базу, резервные копии и пользовательские скриншоты.
- Не добавлять контейнеризацию, авторизацию или многопользовательский режим.
- Не публиковать сайт, не отправлять сообщения, не пушить изменения и не менять настройки GitHub.
- Сохранять рабочие API, миграции и публичные экспорты shared.
- Сначала зафиксировать результат существующих проверок, затем повторить их после рефакторинга.

## Решения исполнителя

MIT выбрана как простая разрешительная лицензия; автор — Andrey Piskunov, год — 2026. Исходники восстанавливаются только по списку отсутствующих отслеживаемых файлов из `be77853`.
