# Первый запуск

master-ai запускается локально: браузерный интерфейс работает на Vite, API хранит данные в SQLite. Интерфейс приложения на русском языке.

## Что понадобится

- Git.
- Node.js 22. Поддерживаемый диапазон — `>=22.9.0 <23`; точная версия записана в [.nvmrc](../.nvmrc).
- pnpm 9.15.9 через Corepack.
- Для ИИ-функций: отдельно установленный и авторизованный CLI-клиент либо ключ OpenAI-совместимого API.

Просматривать и редактировать материалы можно без подключения ИИ. Установка зависимостей требует доступа к реестру пакетов.

## Установка

```sh
git clone https://github.com/andrewpiskunov/master-ai.git
cd master-ai
corepack enable
corepack prepare pnpm@9.15.9 --activate
pnpm install --frozen-lockfile
```

Если используете nvm, перед установкой зависимостей выполните `nvm install` и `nvm use` в корне проекта.

Для стандартного CLI-провайдера файл настроек необязателен. Чтобы изменить команду, скопируйте пример:

```sh
cp .env.example .env
```

Допустимые параметры и настройка API описаны в [руководстве по настройке](configuration.md).

## Запуск

```sh
pnpm dev
```

Откройте [http://localhost:5173](http://localhost:5173). API работает на `http://127.0.0.1:5174`; запросы `/api` интерфейс передаёт ему через Vite. Если порт интерфейса занят, ориентируйтесь на адрес в выводе Vite.

При первом запуске сервер создаст `packages/server/data/master-ai.sqlite` и применит миграции. Данные сохраняются между перезапусками. Чтобы остановить оба процесса, нажмите `Ctrl+C` в терминале.

## Открыть пример

Оставьте `pnpm dev` запущенным. В другом терминале из корня проекта выполните:

```sh
pnpm demo:import
```

Команда импортирует [вымышленную кампанию](../examples/demo-campaign.json) через локальный API. Обновите главную страницу и откройте созданную кампанию. Повторный импорт создаёт ещё одну кампанию.

Если кампания уже открыта, импортировать файл можно через «Управление кампанией» → «Экспорт и импорт» → «Импорт из JSON». После импорта ключ API нужно ввести заново.

## Начать свою кампанию

На главной странице создайте кампанию, задайте название и при желании игровую систему. Внутри кампании откройте «Управление кампанией» → «Нейросеть» и выберите способ подключения ИИ.

Добавляйте материалы в базу знаний или обсуждайте идеи в мастерской. Перед игровым сеансом откройте режим игры и подготовьте нужные документы. ИИ может ошибаться в фактах, правилах и связях сюжета; проверяйте предложенные изменения перед принятием.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| `pnpm` не найден | Выполните команды Corepack из раздела установки и снова откройте терминал. |
| Ошибка загрузки `better-sqlite3` после смены Node.js | Переключитесь на Node.js из `.nvmrc` и выполните `pnpm rebuild better-sqlite3`. |
| Интерфейс открыт, но кампании не загружаются | Убедитесь, что процесс API запустился и порт `5174` свободен. |
| Не удаётся запустить CLI | Проверьте команду и авторизацию клиента из того же терминала, где запускаете приложение. |
| Выбран API, но запускается CLI | В настройках кампании должен быть заполнен API-ключ. Пустой ключ включает запасной CLI-провайдер. |

Перед обновлением прочитайте [инструкцию по резервным копиям](backup-and-updates.md).
