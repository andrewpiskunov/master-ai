# Приёмы оформления README

Для оформления master-ai рассмотрены три README проектов с разными способами представить продукт. Сравнение касается структуры и навигации, без рейтинга проектов.

| Пример | Наблюдение | Применение в master-ai |
| --- | --- | --- |
| [Excalidraw](https://github.com/excalidraw/excalidraw/blob/master/README.md) | В начале стоит короткое описание продукта и ссылки на редактор и документацию. Возможности собраны в отдельном разделе. Quick start прямо уточняет, что установка npm-пакета и запуск репозитория для разработки описываются разными инструкциями. | Коротко объяснить назначение, показать интерфейс, дать один проверяемый локальный запуск. Подробности разработки вынести в отдельное руководство. |
| [Immich](https://github.com/immich-app/immich/blob/main/README.md) | После описания доступны переводы, ссылки на документацию, установку, demo и участие. Возможности сопоставлены в таблице по платформам. | Дать переключение языка README и заметную навигацию по задачам. Открывать знакомство с проектом через демонстрационные данные и реальные скриншоты. |
| [Paperless-ngx](https://github.com/paperless-ngx/paperless-ngx/blob/main/README.md) | README объясняет, что делает продукт, показывает интерфейс и ведёт к подробной документации. Запросы функций, ошибки и вклад в разработку имеют отдельные направления. Ограничения хранения чувствительных данных описаны явно. | Развести запуск, сообщения об ошибках и правила вклада ссылками на соответствующие файлы. Рядом с возможностями назвать локальный режим, отсутствие авторизации и особенности API-ключей. |

## Структура README master-ai

Первый экран объясняет назначение помощника ведущего НРИ и показывает его внешний вид. Затем идут сценарии использования, локальный запуск, подключение ИИ и ограничения. Таблица ссылок направляет к настройке, архитектуре, резервным копиям и правилам участия.

Изображения сняты на вымышленной кампании из `examples`, чтобы показать рабочие экраны без личных материалов. Английский README описывает те же условия запуска и указывает, что интерфейс приложения на русском языке.
