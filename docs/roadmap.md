# Направления развития

Это предложения для обсуждения, без сроков и обещаний реализации. Приоритет зависит от воспроизводимых проблем и сценариев использования. Готовые возможности перечислены в [README](../README.md), изменения — в [CHANGELOG](../CHANGELOG.md).

| Направление | Какую задачу стоит разобрать |
| --- | --- |
| Первый запуск ИИ | Проверять доступность CLI и объяснять ошибки авторизации до отправки большого запроса. |
| Работа с предложениями | Сделать предварительный просмотр изменений и их последствий для связанных материалов понятнее. |
| Перенос кампаний | Давать подробную диагностику некорректного файла и проверять целостность связей перед импортом. |
| Длинные кампании | Изучить поиск, карту связей и выбор контекста на больших наборах документов. |
| Интерфейс и доступность | Проверить основные сценарии с клавиатуры, подписи элементов и работу на узком экране. |
| Надёжность данных | Упростить проверку резервной копии и восстановление на отдельной тестовой базе. |

Для предложения создайте [issue](https://github.com/andrewpiskunov/master-ai/issues/new/choose): опишите ситуацию за игровым столом или при подготовке, ожидаемый результат и способ проверить улучшение. Конкретный пример кампании на вымышленных данных помогает оценить задачу.
