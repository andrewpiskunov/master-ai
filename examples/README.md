# Демонстрационная кампания

[«Маяк на краю бурь»](demo-campaign.json) — короткое вымышленное приключение для знакомства с master-ai: 10 документов, 12 связей и пример разговора в мастерской. Все тексты можно свободно менять; правила конкретной игровой системы не требуются.

Запусти приложение из корня репозитория:

```bash
pnpm dev
```

В другом терминале, тоже из корня:

```bash
pnpm demo:import
```

Команда отправит JSON в локальный API на `127.0.0.1:5174` и выведет ссылку на новую кампанию. Каждый запуск создаёт отдельную копию. Существующие кампании сохраняются.

Если кампания уже есть, этот же файл можно выбрать в её разделе «Управление кампанией» → «Экспорт и импорт» → «Импорт из JSON». Импорт также создаст новую кампанию.

Для просмотра и редактирования примера нейросеть не нужна. Записанный в JSON диалог — часть демонстрационных данных, а не результат нового запроса. Чтобы продолжить разговор с ИИ, настрой [провайдер](../docs/configuration.md).

```bash
# Проверка примера в отдельной базе в памяти, без запущенного сервера
pnpm demo:check
```

Проверка проходит через настоящий API импорта, экспорта и поиска, сверяет связи и повторный импорт. Файл не содержит API-ключей, персональных данных или материалов чужих игровых миров.
