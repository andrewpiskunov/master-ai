# @master-ai/web

Браузерный интерфейс MasterAI на React, TypeScript и Vite. Здесь находятся список кампаний, рабочее пространство мастера, редактор документов на Tiptap, ИИ-помощники и режим проведения игры. Интерфейс на русском языке.

Общий порядок установки и настройки ИИ описан в [README репозитория](../../README.md). Команды ниже выполняются из корня репозитория после `pnpm install`.

## Запуск и проверки

```sh
# Сервер и интерфейс вместе
pnpm dev

# Только интерфейс, если сервер уже запущен
pnpm --filter @master-ai/web dev

pnpm --filter @master-ai/web test
pnpm --filter @master-ai/web typecheck
pnpm --filter @master-ai/web build
```

Vite открывает интерфейс на `http://localhost:5173` и перенаправляет запросы `/api` на `http://127.0.0.1:5174`. Адрес сервера задаётся в `vite.config.ts`. Браузер обращается к серверу через `src/api/`; ключи провайдеров ИИ настраиваются на сервере.

Результат сборки попадает в `dist/`. Для просмотра можно выполнить `pnpm --filter @master-ai/web preview`; Vite использует тот же прокси `/api`, поэтому сервер должен быть запущен. Сборка выделяет зависимости редактора в `editor`, остальные внешние зависимости в `vendor`. Проверка типов запускается отдельно от сборки.

## Структура

```text
packages/web/
├── index.html
├── public/favicon.svg
├── src/
│   ├── app/
│   │   ├── main.tsx              # Подключение React и глобальных стилей
│   │   ├── App.tsx               # Маршруты и провайдеры
│   │   ├── styles.css
│   │   └── test-setup.ts
│   ├── api/
│   │   ├── client.ts             # Типизированные запросы к серверу
│   │   └── stream.ts             # Чтение потоковых ответов
│   ├── features/
│   │   ├── campaigns/            # Список, навигация, библиотека, настройки и экспорт
│   │   ├── documents/            # Документ, печать, обратные ссылки
│   │   │   └── editor/           # Tiptap, расширения и конвертеры
│   │   ├── assistant/            # Мастерская, беседы и предложения ИИ
│   │   └── play/                 # Игровой чат, материалы, бой и броски кубиков
│   ├── hooks/
│   │   ├── useBookmarks.ts
│   │   └── useGoBack.ts
│   ├── lib/                      # Форматирование, упоминания, diff и извлечение текста
│   └── ui/                       # Общие элементы интерфейса
├── tsconfig.json
└── vite.config.ts
```

Тесты `*.test.ts` и `*.test.tsx` лежат рядом с проверяемым кодом и в дереве выше опущены. Vitest использует jsdom и Testing Library. В `app/test-setup.ts` подключаются проверки DOM из `@testing-library/jest-dom`.

## Где вносить изменения

Код экрана и его компоненты храните в соответствующей папке `features/`. Общие элементы интерфейса кладите в `ui/`, хуки в `hooks/`, независимые вспомогательные функции в `lib/`. Если функция нужна только одной части приложения, оставляйте её внутри этой части; например, конвертеры документа находятся в `features/documents/editor/`.

Маршруты собраны в `app/App.tsx`. Оболочка кампании передаёт состояние вложенным экранам через outlet-контекст из `features/campaigns/shared.tsx`. Беседа мастерской хранится в `features/assistant/WorkshopChatContext.tsx`, чтобы переход между экранами кампании сохранял её состояние.

Типы API и описания документов импортируются из `@master-ai/shared`. Относительные импорты в TypeScript и пути в моках Vitest пишутся с расширением `.js`: это соглашение проекта для `NodeNext`. При переносе файла обновляйте и импорты, и моки.

Паритет браузерного и серверного преобразования Markdown проверяет `features/documents/editor/convparity.test.ts`. При изменении формата документа сверяйте оба конвертера и их тесты.
