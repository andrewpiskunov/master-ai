# @master-ai/shared

Общие контракты клиента и сервера: Zod-схемы, типы документов, шаблоны и функции разбора игрового текста. Пакет не зависит от React, Fastify или базы данных.

```text
src/
├── index.ts       # Публичные экспорты пакета
├── schemas/       # Кампании, документы, связи, предложения и API-контракты
├── registries/    # Типы документов, статусы, шаблоны и подсказки
└── lib/           # Разбор ответов ИИ-мастера и игрового лога
```

Тесты лежат рядом с проверяемыми файлами. Новые контракты экспортируются через `src/index.ts`; другие пакеты импортируют их из `@master-ai/shared`, без обращения к внутренним папкам.

```bash
# Из корня репозитория
pnpm --filter @master-ai/shared test
pnpm --filter @master-ai/shared typecheck
```

В workspace пакет отдаёт исходники TypeScript: их обрабатывают Vite, tsx и Vitest. Отдельная публикация в npm пока не настроена.

См. [архитектуру](../../docs/architecture.md) и [руководство разработчика](../../docs/development.md).
